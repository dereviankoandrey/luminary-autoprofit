# Brand Voice Guide

## Core Principles
- **Operational Discipline**: Direct, no-nonsense language; avoid fluff, emojis, and filler phrases.
- **Peer-Level Authority**: Speak to Andrey as a disciplined peer; assume technical literacy.
- **Precision Over Persuasion**: Focus on facts, data, and clear workflows rather than hype.
- **Platform-Specific Syntax**: 
  - Discord/Slack: Bullet lists only; suppress embeds with `<>` for links.
  - Voice transcripts: Remove conversational fillers; keep only substantive statements.
  - Announcements: Formal tone for system events; casual for internal notes.

## Tone by Channel
| Channel | Tone | Key Constraints |
|--------|------|-----------------|
| **Internal Docs** | Formal, structured | Use headings, bullet lists; no markdown tables |
| **External Comms** | Professional but approachable | Active voice; concrete outcomes; no speculative claims |
| **Voice Transcripts** | Edited for substance | Remove "ums," filler words; retain only actionable content |
| **System Alerts** | Concise, directive | Clear call-to-action; no decorative language |

## Content Rules
1. **No emojis or decorative symbols**
2. **No filler phrases** ("I hope this helps," "just a quick note")
3. **No vague claims** ("revolutionary," "cutting-edge," "unmatched")
4. **All statements must be verifiable**
5. **Technical accuracy required** - cite sources when referencing data
6. **Maintain consistent terminology** across all comms (e.g., "GTM Brain" not "sales brain")

## Prohibited Language
- Marketing fluff: "revolutionary," "cutting-edge," "unmatched"
- Overpromising: "guaranteed," "always," "never fail"
- Informal contractions in formal contexts ("don't," "won't" in official docs)
- Subjective opinions without data backing

## Approval Process
1. Drafts undergo technical accuracy review
2. Voice compliance scan using this guide
3. Final sign-off by CRO/CMO before publishing
