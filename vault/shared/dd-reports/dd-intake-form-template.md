# DD Reports — Deal Intake Form Template

**Purpose:** Standardized intake so we can generate accurate, actionable due diligence reports without back-and-forth clarification.

**Instructions for investor:** Fill out all fields you have. Leave blanks where data isn't available — we'll note missing inputs in the report as assumptions with confidence adjustments.

---

## Section 1: Deal Basics

| Field | What to Provide |
|-------|----------------|
| Property address or general location (city + neighborhood) | e.g., "East Austin, Mueller district" or full street address |
| Property type | Multi-family / Fix-and-flip / Development / Commercial / Other |
| Asking price | Total acquisition cost |
| Number of units (if applicable) | e.g., 12, 240, 3 |
| Current condition | Occupied / Vacant / Renovation needed / Ground-up build site |

## Section 2: Financial Inputs

| Field | What to Provide |
|-------|-----------------|
| Acquisition price | Total purchase price (land + existing structure) |
| Down payment % or amount | e.g., 25% of acquisition price |
| Interest rate assumption | Current rate you expect (or leave blank for market average estimate) |
| Holding period (months) | How long you plan to hold before sale or refinancing |
| Construction budget (if applicable) | Total rehab/build cost in dollars |
| After-repair value (ARV) | Your projected end value — include how you arrived at it if possible |
| Expected selling costs % | Typically 5-8% for agent commissions + closing costs |

## Section 3: Market Context (what you know)

| Field | What to Provide |
|-------|-----------------|
| Comparable sales you've identified | Addresses or links, sale price, date |
| Rent comps (if multi-family/hold strategy) | Current rents in the area per unit |
| Zoning information | If known (e.g., "MF-4", "single-family") |
| Any inspections already completed | Phase I ESA, property inspection, survey results |

## Section 4: Strategy & Goals

| Field | What to Provide |
|-------|-----------------|
| Investment strategy | Buy-and-hold / Flip / Development / BRRRR / Other |
| Target metrics | Minimum IRR, equity multiple, or profit target if you have one |
| Financing approach | Conventional loan / Hard money / Cash / Seller financing / Mixed |

## Section 5: Anything Else

Free text field for any additional context, constraints, or specific questions you want addressed in the report.

---

*This intake form is designed to be completed in under 10 minutes. If you're unsure about a field, estimate and note it as an assumption — we'll factor that into the report's confidence scoring.*
