## Intake form fields
### Required
- full name
- company
- email
- role
- company type: developer / acquisitions / lender / consultant / other
- team size
- main Austin workflow: underwriting / acquisitions / entitlement / lending / internal reporting / other
- main pain point
- preferred tier: solo / team / not sure

### Helpful but optional
- phone
- website
- current method for monitoring Austin process changes
- how often Austin workflow is active: weekly / monthly / occasional
- preferred delivery format: email PDF / email text / both
- preferred delivery recipients if team plan
- anything that would make the brief clearly worth paying for

## Qualification rules
### Strong fit
A pilot lead is strong if at least 3 are true:
- active in Austin or Greater Austin development workflow
- exposed to entitlement, permit, capital, or timeline risk
- currently checks scattered public sources manually or inconsistently
- can buy a low-ticket pilot without heavy procurement friction
- wants repeatable signal monitoring, not bespoke parcel research

### Weak fit
Deprioritize if:
- wants generic Austin real estate news
- wants one-off consulting on a single property
- has no current Austin activity
- cannot identify a workflow owner or user

## What happens next
1. intake is reviewed for fit
2. qualified leads get a sample issue if they have not already seen one
3. pilot tier and delivery format are confirmed
4. payment/setup link is sent
5. subscriber is added to the next issue cycle

## Post-intake response template
Hi [Name] — thanks. This looks like a good fit for the Austin Entitlement Signal Brief pilot.

Next step is simple: I’ll confirm the best tier, send over the payment/setup step, and add you to the next issue cycle.

If helpful, I can also send the strongest recent sample issue first.

## If not a fit template
Thanks for the detail. I don’t think the current pilot is the right fit yet.

It is built for recurring Austin entitlement/permit monitoring rather than bespoke deal work or broad market news. If that changes later, I can circle back.
