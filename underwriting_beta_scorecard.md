# AI Underwriting SaaS — Beta Scorecard

## Purpose
Score beta demos consistently so Luminary can tell the difference between polite interest and real paid-beta demand.

## Ideal Customer Profile Check
- [ ] Screens 5+ deals/month
- [ ] Small operator, lender, broker, or lean GP team
- [ ] Current first-pass screening is manual, inconsistent, or slow
- [ ] Would benefit from faster deal triage before full underwriting

**ICP fit score (0-3):** 
- 0 = poor fit
- 1 = partial fit
- 2 = good fit
- 3 = strong fit

## Validation Questions
### 1) Pain severity
How painful is the current screening workflow?
- 0 = not painful
- 1 = mild annoyance
- 2 = meaningful friction
- 3 = urgent / costly pain

### 2) Frequency
How often would they realistically use this?
- 0 = rarely
- 1 = monthly
- 2 = a few times per month
- 3 = weekly or more

### 3) Time savings belief
Do they believe this would save time or kill weak deals earlier?
- 0 = no
- 1 = maybe
- 2 = likely
- 3 = definitely

### 4) Trust threshold
Do they trust first-pass outputs enough to use on live deals?
- 0 = no trust
- 1 = needs major proof
- 2 = open with some proof
- 3 = ready to try on live deals

### 5) Pricing acceptance
Reaction to $197/month self-serve pricing:
- 0 = clearly too high
- 1 = hesitant
- 2 = plausible
- 3 = fair / easy yes

## Decision Rule
**Total score: /15**
- 12-15 = strong paid-beta candidate
- 8-11 = keep warm, needs proof/demo follow-up
- 0-7 = weak candidate
