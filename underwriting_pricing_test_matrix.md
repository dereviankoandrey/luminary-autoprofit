# AI Underwriting SaaS — Pricing Test Matrix

## Purpose
Give Luminary a simple way to test price acceptance during the first beta demos without improvising.

## Pricing Anchors

### Option A — Self-Serve Beta
- **$197/month**
- 1 user
- first-pass deal screening
- sample exports / summary output
- email support

### Option B — Team Beta
- **$497/month**
- up to 3 users
- shared workflow for lean acquisition team
- priority feedback loop
- light onboarding

### Option C — Concierge Beta
- **$1,500 setup + $500/month**
- workflow setup help
- custom rubric tuning
- higher-touch support
- reserved for teams that want hand-holding

## Demo Pricing Script
1. Confirm current workflow and pain.
2. Show one sample deal result.
3. Ask whether they would use it on live screening.
4. Test price in this order:
   - $197/month self-serve
   - if team use case appears, test $497/month
   - only mention concierge if they ask for customization

## Response Scoring
### $197/month
- **Strong yes:** says fair / easy / obvious
- **Soft yes:** wants proof or short trial first
- **Weak:** says maybe later / not priority
- **No:** says too high or no need

### $497/month
- **Strong yes:** team workflow pain is obvious and current process is costly
- **Soft yes:** wants proof, procurement, or more seats/value
- **Weak/No:** defaults back to solo or manual workflow

## Decision Rules
- If 2 of first 3 qualified prospects react positively to **$197/month**, keep self-serve beta as default.
- If multiple prospects ask for team workflow, test **$497/month** packaging more aggressively.
- If prospects mainly want customization, avoid overcommitting and keep concierge beta limited.
- If all 3 prospects reject pricing, re-check pain severity before lowering price.

## What To Log Per Demo
- Prospect / company
- Segment
- Monthly deal volume
- Current screening method
- Price shown first
- First reaction
- Objection stated
- Would start with trial? Y/N
- Would pay now if screenshots/demo looked credible? Y/N
- Best-fit package: Self-serve / Team / Concierge / None

## Success Threshold
- **Pass:** at least 2 prospects indicate self-serve or team beta is plausibly payable.
- **Mixed:** interest is real but trust proof is missing.
- **Fail:** pain exists but pricing is consistently rejected.
