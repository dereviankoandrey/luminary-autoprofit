# AI Underwriting SaaS — Beta Demo Script v1

## Purpose
Give Luminary a fixed, low-friction script for the first beta demos so pricing, objections, and next steps are tested consistently.

## Demo Goal
Show one realistic deal screen in under 10 minutes, confirm pain severity, and test whether the buyer would plausibly pay for a beta.

## Who This Is For
- small acquisitions teams
- lenders screening inbound opportunities
- operators doing first-pass deal triage

## 10-Minute Flow

### 1. Setup (1 minute)
- Confirm their current screening workflow.
- Ask how many deals they review per week.
- Ask what slows down first-pass decisions today.

### 2. Positioning (1 minute)
Use this framing:

> "This is a first-pass underwriting screen for fast GO / REVIEW / NO-GO decisions. It is meant to reduce time spent on weak deals before deeper underwriting starts."

### 3. Product Walkthrough (3 minutes)
Show:
- inputs required
- recommendation output
- green flags
- red flags
- how a screened deal could be logged or exported later

### 4. Trust Check (2 minutes)
Ask:
- "Would this be useful on live deals or only as a demo artifact?"
- "What would you need to trust it enough to use it weekly?"
- "Where could this fail in your current workflow?"

### 5. Pricing Test (2 minutes)
Test in this order:
1. $197/mo self-serve
2. $497/mo team beta if multi-user workflow appears relevant
3. Concierge only if they ask for custom setup

### 6. Close (1 minute)
Ask for one concrete next step:
- trial
- follow-up after screenshot proof
- waitlist
- no fit

## Minimum Data To Capture
- prospect name
- company / role
- weekly deal volume
- current process
- trust blocker
- first pricing reaction
- best-fit package
- next step

## Pass / Fail Standard
This script helps the experiment pass if:
- the prospect quickly understands the product,
- can map it to an existing workflow,
- and gives a concrete yes / trial / conditional-next-step response instead of vague interest.

## Why This Matters
A fixed script reduces noisy beta feedback and makes it easier to compare reactions across the first 3 demos.
