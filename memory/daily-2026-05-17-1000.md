## Task Chosen
Implemented the missing "development" deal type analyzer in the underwriting engine.

## Why This Task
The underwriting MVP already had thresholds defined for development deals (min IRR 18%, min equity multiple 2.0x, max hold 36 months) but zero implementation. Any development deal passed to `analyze_deal()` fell through to the catch-all "unknown property type" path. Given that development is Andrey's core business and the underwriting SaaS needs to handle his actual deal types, this was dead code blocking the tool's usefulness.

## Work Completed
1. **Added `calculate_development(data)` function** — full development underwriting calculator that computes:
   - Total project cost (land + hard costs + soft costs + financing + sales commissions)
   - Profit and ROI
   - Equity invested, equity multiple, return on equity
   - Simplified IRR approximation
   - Per-unit cost and revenue (when unit count provided)
   - Auto-estimates soft costs at 15% of hard costs if not provided
   - Auto-estimates financing costs from debt percent, interest rate, and hold period

2. **Wired the development branch into `analyze_deal()`** with proper flag logic:
   - Checks simplified IRR against 18%/15% thresholds
   - Checks equity multiple against 2.0x/1.5x thresholds
   - Flags negative project ROI
   - Flags extended holding periods beyond 36 months
   - Checks per-unit margin for thin/healthy pricing

3. **Added 2 new test cases** (Test 5: strong development GO, Test 6: weak development NO-GO)

4. **Validated** — all 6 test cases now pass (4 original + 2 new development):
   - 2 fix-and-flip (1 GO, 1 NO-GO)
   - 2 multifamily (1 GO, 1 NO-GO)
   - 2 development (1 GO, 1 NO-GO)
