# Project Priority Brief

**Last updated:** 2026-04-17 10:00 UTC  
**Purpose:** concise one-page prioritization layer for the active development pipeline so attention goes first to the projects with the highest strategic leverage and the biggest current information gaps.

## Why this exists
The business now has:
- a goals tracker
- a development operating sheet
- a capital/outreach tracker
- a weekly review template
- a development update request packet

What was still missing was a simple ranking lens for where to focus first when live updates start coming in. This brief solves that.

## Current Priority Ranking

### 1. Laguna Marble Falls
**Why first:** largest project in the pipeline, highest leverage, highest potential capital complexity.

**What is known**
- Mixed-use
- 463 acres
- 3,293 units + 321 townhomes + 745 homes + 2 hotels + 100,000 SF retail
- Indicative end value > $2B

**Why it matters now**
- Biggest upside if capital and partner tracking gets organized
- Biggest risk if status and counterparties stay unclear

**Immediate information needed**
- Current land/control and approvals status
- Current capital ask and timing
- Named counterparties already in motion
- Single next decision or meeting needed

### 2. Leander Springs
**Why second:** very large mixed-use opportunity with likely segmented capital-stack complexity.

**What is known**
- 79 acres
- 1,600 units
- 2 hotels
- 1,000,000+ SF retail
- Indicative end value > $1.5B

**Why it matters now**
- Requires clear deal narrative and component-by-component capital strategy
- Easy for a project of this size to drift if counterparties and milestones are not explicit

**Immediate information needed**
- Current entitlement/deal status
- Capital stack concept by component
- Best-fit institutional and strategic counterparties
- Most urgent next milestone

### 3. ZFB at Anderson Mill
**Why third:** smaller than the top two but likely the cleanest candidate for underwriting-led investor readiness.

**What is known**
- Multifamily
- up to 280 units
- Indicative end value ~$90M

**Why it matters now**
- Good candidate for a tight financing and investor-readiness push
- More executable near-term if underwriting and capital stack are clarified

**Immediate information needed**
- Current execution stage
- Underwriting version / readiness status
- Target debt/equity counterparties
- Next diligence milestone

## Secondary Priority Group

### 4. Emeral Ranch
Material project, but lower leverage than the top three until current milestone and funding need are clarified.

### 5. Twilight Estate
Execution-focused; likely important operationally, but less strategic leverage than the larger mixed-use projects.

### 6. Manor Townhomes
Smaller project with value in near-term execution visibility, but not the top strategic priority right now.

## Recommended Operating Sequence
1. Gather live updates for Laguna Marble Falls
2. Gather live updates for Leander Springs
3. Gather live updates for ZFB at Anderson Mill
4. Update the operating sheet and capital tracker for those three first
5. Run the first weekly pipeline review after those updates are captured

## Decision Rule
If time is limited, work top-down by:
1. largest strategic value
2. nearest capital or partner dependency
3. clearest next action once live facts are available
