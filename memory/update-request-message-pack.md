# Update Request Message Pack

**Last updated:** 2026-04-24 10:00 UTC  
**Purpose:** provide copy-paste message drafts that make it easy to collect the missing live project facts and underwriting beta candidates without rewriting the ask each time.

## Why this exists
The main operating bottleneck is still missing live inputs:
- current stage
- blocker
- milestone date
- capital ask
- named counterparties
- underwriting beta candidates

The workspace already has the structure to process those answers once they arrive. What was still missing was a ready-to-send message pack that reduces friction for asking.

## Best first recipient
**Primary:** Andrey  
**Where:** whichever channel he is most likely to answer fastest — direct text, email, or chat

If Andrey prefers delegation, the same drafts can be sent to the relevant internal project lead or analyst for each project.
