# Weekly Development Review Output Sheet

**Last updated:** 2026-04-20 10:00 UTC  
**Purpose:** ready-to-run weekly meeting output sheet that captures the exact decisions, follow-ups, and tracker changes needed after each development pipeline review.

## Why this exists
The business already has:
- a weekly review template
- a development operating sheet
- a capital/outreach tracker
- a top-3 briefing pack
- an execution board
- an update ingestion log

What was still missing was a single post-review output page that answers, in one place:
1. what changed this week
2. what must be updated in the trackers
3. what follow-ups are due now
4. what decisions Andrey needs to make

This document closes the gap between reviewing the pipeline and actually updating the system.

## How to use
1. Run the weekly review using `memory/weekly-development-review-template.md`
2. Record the review outcomes here in the same session
3. Push the reviewed facts into the operating sheet, capital tracker, briefing pack, ingestion log, and execution board
4. Leave nothing implied: every follow-up should have an owner and due date
